## 特性

- ✅ 自动过 **自学任务**
- ✅ 自动过 **班级任务**
- ✅ 99+ 正确率，支持循环刷到满分
- ✅ Web 控制台一键启动 / 停止 / 看日志
- ✅ 本地题库持续累积，越用越快；匹配不到时可选 LLM 兜底

## 快速开始

### 1. 安装依赖

```bash
uv sync
```

或：

```bash
pip install -e .
```

也可以**不手动编辑**，直接启动 Web 控制台，在页面中填写并保存，系统会自动写入 `.env`。

### 2. 启动 Web 控制台

```bash
python -m cidaren
```

默认地址：`http://localhost:5000`

## 使用方式

1. 打开 Web 控制台
2. 在页面顶部的 **配置中心** 填入 token / LLM 变量
3. 在 **任务面板** 刷新任务并启动
4. 如需一直刷到满分，点击 `🔁 循环`
